📚 按 .NET 版本导航 ​

.NET 8 (LTS) ​

所有标注 ✅ 的功能均支持 .NET 8

新特性：

  • 批量操作 API
  • JSON 列基础支持
  • 复合拆分查询

.NET 9 (STS) ​

包含 .NET 8 全部功能 +

新特性：

  • JSON 列高级功能
  • 改进的迁移体验
  • 性能优化增强

.NET 10 (预览版) ​

🚧 实验性功能，生产环境谨慎使用

新特性：

  • AI 辅助查询优化（预览）
  • 云原生集成增强
  • 更智能的查询翻译
