.NET CLI 命令参考 ​

概述 ​

.NET CLI (Command-Line Interface) 是 EF Core 迁移和脚手架的主要工具。本文档提供完整的命令参考。

安装 EF Core CLI ​

bash
# 全局安装(推荐)
dotnet tool install --global dotnet-ef

# 验证安装
dotnet ef --version

# 更新到最新版本
dotnet tool update --global dotnet-ef

# 项目级别安装
dotnet new console
dotnet tool install dotnet-ef

迁移命令 ​

创建迁移 ​

bash
# 基本语法
dotnet ef migrations add <MigrationName>

# 示例
dotnet ef migrations add InitialCreate
dotnet ef migrations add AddUserTable
dotnet ef migrations add UpdateProductSchema

# 指定输出目录
dotnet ef migrations add InitialCreate --output-dir Migrations

# 指定 DbContext
dotnet ef migrations add InitialCreate --context AppDbContext

# 指定项目(多项目方案)
dotnet ef migrations add InitialCreate \
  --project src/Infrastructure \
  --startup-project src/WebApi

# 自定义命名空间
dotnet ef migrations add InitialCreate \
  --namespace MyCompany.MyApp.Migrations

应用迁移 ​

bash
# 应用到最新迁移
dotnet ef database update

# 应用到特定迁移
dotnet ef database update AddUserTable

# 回滚所有迁移(清空数据库)
dotnet ef database update 0

# 指定连接字符串
dotnet ef database update \
  --connection "Server=localhost;Database=MyApp;..."

# 指定环境
dotnet ef database update --environment Production

数据库命令 ​

生成 SQL 脚本 ​

bash
# 生成从空数据库到最新迁移的脚本
dotnet ef migrations script

# 生成特定范围的脚本
dotnet ef migrations script InitialCreate AddUsers

# 生成幂等脚本(可重复执行)
dotnet ef migrations script --idempotent

# 输出到文件
dotnet ef migrations script --output migrations.sql

# 不包含事务
dotnet ef migrations script --no-transactions

脚手架命令 ​

从数据库生成代码 ​

bash
# 基本语法
dotnet ef dbcontext scaffold "<connection_string>" <provider>

# SQL Server 示例
dotnet ef dbcontext scaffold \
  "Server=localhost;Database=AdventureWorks;Trusted_Connection=True;" \
  Microsoft.EntityFrameworkCore.SqlServer

# PostgreSQL 示例
dotnet ef dbcontext scaffold \
  "Host=localhost;Database=adventureworks;Username=postgres;Password=pass" \
  Npgsql.EntityFrameworkCore.PostgreSQL

# MySQL 示例
dotnet ef dbcontext scaffold \
  "Server=localhost;Database=adventureworks;Uid=root;Pwd=pass" \
  Pomelo.EntityFrameworkCore.MySql

# 完整参数
dotnet ef dbcontext scaffold \
  "Server=localhost;Database=MyApp;Trusted_Connection=True;" \
  Microsoft.EntityFrameworkCore.SqlServer \
  --output-dir Models \
  --context-dir Data \
  --context MyAppContext \
  --schema dbo \
  --table Users \
  --table Products \
  --data-annotations \
  --force \
  --no-pluralize \
  --use-database-names

参数说明 ​

参数简写说明
--output-dir-o实体类输出目录
--context-dir-DbContext 输出目录
--context-DbContext 类名
--schema-指定架构(逗号分隔)
--table-t指定表(可多个)
--data-annotations-使用数据注解
--force-f覆盖现有文件
--no-pluralize-禁用复数化
--use-database-names-使用数据库名称
--namespace-n自定义命名空间

实际工作流示例 ​

新项目初始化 ​

bash
# 1. 创建项目
dotnet new webapi -n MyApp
cd MyApp

# 2. 添加 EF Core 包
dotnet add package Microsoft.EntityFrameworkCore.SqlServer
dotnet add package Microsoft.EntityFrameworkCore.Tools

# 3. 创建第一个迁移
dotnet ef migrations add InitialCreate

# 4. 应用迁移
dotnet ef database update

# 5. 验证
dotnet ef migrations list

✅ 推荐做法 ​

1. 使用描述性的迁移名称 ​

bash
# ✅ 好
dotnet ef migrations add AddUserEmailAndPhone
dotnet ef migrations add CreateOrdersTable
dotnet ef migrations add MakeProductNameRequired

# ❌ 差
dotnet ef migrations add Update
dotnet ef migrations add Change
dotnet ef migrations add Fix

1. 不要手动编辑迁移文件 ​

常用命令速查表 ​

任务命令
创建迁移dotnet ef migrations add <Name>
应用迁移dotnet ef database update
删除迁移dotnet ef migrations remove
列出迁移dotnet ef migrations list
生成脚本dotnet ef migrations script
删除数据库dotnet ef database drop
脚手架dotnet ef dbcontext scaffold
优化模型dotnet ef dbcontext optimize

核心要点 ​

  1. CLI 是首选工具: 比 PMC 更跨平台
  2. 描述性命名: 迁移名称要清晰
  3. 幂等脚本: 生产部署必须使用
  4. 版本控制: 迁移文件必须纳入 Git
  5. 团队协作: 沟通迁移变更
