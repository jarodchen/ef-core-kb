DbContext 的职责 ​

DbContext 是 EF Core 的**工作单元（Unit of Work）和仓储（Repository）**模式的实现。

Web 应用（Scoped） ​

推荐配置：

csharp
// Program.cs
builder.Services.AddDbContext<AppDbContext>(options =>
    options.UseSqlServer(connectionString));

        }
    } // context 自动释放

✅ 正确的并发处理方式 ​

方案 1：每个操作创建新的 DbContext ​

csharp
private readonly IServiceScopeFactory _scopeFactory;

public async Task ProcessProductsAsync()
{
    var tasks = Enumerable.Range(0, 100).Select(async i =>
    {
        // 每个任务创建独立的 scope 和 DbContext
        await using var scope = _scopeFactory.CreateAsyncScope();
        var context = scope.ServiceProvider.GetRequiredService<AppDbContext>();
        
        context.Products.Add(new Product { Name = $"Product {i}" });
        await context.SaveChangesAsync();
    });

    await Task.WhenAll(tasks);
}

高级用法 ​

1. 重写 SaveChangesAsync ​

csharp
public class AuditableDbContext : DbContext
{
    public override async Task<int> SaveChangesAsync(
        CancellationToken cancellationToken = default)
    {
        // 自动填充审计字段
        var entries = ChangeTracker.Entries<IAuditable>();
        
        foreach (var entry in entries)
        {
            switch (entry.State)
            {
                case EntityState.Added:
                    entry.Entity.CreatedAt = DateTime.UtcNow;
                    entry.Entity.CreatedBy = GetCurrentUserId();
                    break;
                    
                case EntityState.Modified:
                    entry.Entity.ModifiedAt = DateTime.UtcNow;
                    entry.Entity.ModifiedBy = GetCurrentUserId();
                    break;
            }
        }
        
        return await base.SaveChangesAsync(cancellationToken);
    }
    
    private string GetCurrentUserId()
    {
        // 从 HttpContext 或 ClaimsPrincipal 获取
        return "system";
    }
}

2. 事务管理 ​

csharp
public async Task TransferMoneyAsync(int fromAccountId, int toAccountId, decimal amount)
{
    await using var transaction = await Database.BeginTransactionAsync();
    
    try
    {
        // 扣款
        var fromAccount = await Accounts.FindAsync(fromAccountId);
        fromAccount.Balance -= amount;
        
        // 收款
        var toAccount = await Accounts.FindAsync(toAccountId);
        toAccount.Balance += amount;
        
        await SaveChangesAsync();
        
        // 提交事务
        await transaction.CommitAsync();
    }
    catch (Exception)
    {
        // 回滚事务
        await transaction.RollbackAsync();
        throw;
    }
}

3. 批量操作优化 ​

csharp
public async Task BulkInsertAsync(IEnumerable<Product> products)
{
    // 禁用自动检测变化
    ChangeTracker.AutoDetectChangesEnabled = false;
    
    try
    {
        await Products.AddRangeAsync(products);
        await SaveChangesAsync();
    }
    finally
    {
        // 恢复自动检测
        ChangeTracker.AutoDetectChangesEnabled = true;
    }
}

5. 拦截器（Interceptors） ​

csharp
public class QueryPerformanceInterceptor : DbCommandInterceptor
{
    private readonly ILogger<QueryPerformanceInterceptor> _logger;

    public QueryPerformanceInterceptor(ILogger<QueryPerformanceInterceptor> logger)
    {
        _logger = logger;
    }

    public override InterceptionResult<DbDataReader> ReaderExecuting(
        DbCommand command,
        CommandEventData eventData,
        InterceptionResult<DbDataReader> result)
    {
        // 记录慢查询
        var stopwatch = Stopwatch.StartNew();
        
        var reader = base.ReaderExecuting(command, eventData, result);
        
        stopwatch.Stop();
        if (stopwatch.ElapsedMilliseconds > 1000)
        {
            _logger.LogWarning("Slow query detected: {Sql} ({Elapsed}ms)", 
                command.CommandText, stopwatch.ElapsedMilliseconds);
        }
        
        return reader;
    }
}

// 注册拦截器
builder.Services.AddDbContext<AppDbContext>(options =>
{
    options.UseSqlServer(connectionString);
    options.AddInterceptors(new QueryPerformanceInterceptor(logger));
});

⚠️ 常见陷阱 ​

1. DbContext 已释放 ​

错误：

Cannot access a disposed context instance.
1

原因：

  • 异步操作中 DbContext 已被释放
  • 跨线程访问 DbContext

解决：

csharp
// 确保 DbContext 在 using 范围内
await using var context = new AppDbContext(options);
var products = await context.Products.ToListAsync();
// 不要在这里继续使用 context
1
2
3
4

2. 跟踪冲突 ​

错误：

The instance of entity type 'Product' cannot be tracked because another instance with the same key value is already being tracked.
1

原因：

  • 多次加载同一实体

解决：

csharp
// 方法 1：使用 AsNoTracking
var product1 = await context.Products.AsNoTracking().FirstOrDefaultAsync(p => p.Id == 1);
var product2 = await context.Products.AsNoTracking().FirstOrDefaultAsync(p => p.Id == 1);

// 方法 2：先检查是否已跟踪
var existing = context.ChangeTracker.Entries<Product>()
    .FirstOrDefault(e => e.Entity.Id == id);
    
if (existing != null)
{
    existing.Entity.Price = 99.99m;
}
else
{
    var product = await context.Products.FindAsync(id);
    product.Price = 99.99m;
}
