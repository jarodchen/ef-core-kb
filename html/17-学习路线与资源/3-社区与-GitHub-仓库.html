提问技巧:

✅ 好的提问 ​

markdown
标题: EF Core 3.1 Include 导致 N+1 查询问题

正文:
【环境】
- EF Core 3.1
- SQL Server 2019
- .NET Core 3.1

【问题描述】
使用 Include 加载导航属性时,发现生成了多个查询

【代码】
var orders = await _context.Orders
    .Include(o => o.Items)
    .ToListAsync();

【生成的 SQL】
-- 查询 1: Orders
SELECT ... FROM Orders

-- 查询 2-N: OrderItems (每个 Order 一个查询!)
SELECT ... FROM OrderItems WHERE OrderId = 1
SELECT ... FROM OrderItems WHERE OrderId = 2
...

【期望】
应该只生成 2 个查询(Orders + OrderItems)

【已尝试】
- 升级到 EF Core 5.0 (问题依旧)
- 使用 ThenInclude (无效)

3. Ardalis.Specification (规范模式) ​

GitHub: https://github.com/ardalis/specification

功能:

  • 封装查询逻辑
  • 可组合的查询
  • 强类型安全

示例:

csharp
public class CustomerByNameSpec : Specification<Customer>
{
    public CustomerByNameSpec(string name)
    {
        Query.Where(c => c.Name.Contains(name));
    }
}

var customers = await customerRepository.ListAsync(new CustomerByNameSpec("John"));
