EF Core 知识库使用指南 ​

如何高效利用本知识库学习和掌握 EF Core

📖 阅读建议 ​

🎯 根据你的角色选择路径 ​

学生/初学者（0-6 个月编程经验） ​

目标：掌握基础 CRUD，能够独立完成小型项目

学习路径：

  1. 第 1 周：概述篇 + 快速入门

    • EF Core 是什么
    • 安装与配置
    • 第一个 DbContext
    • 基础 CRUD 操作

  2. 第 2 周：核心概念基础

    • 定义实体类与 DbSet
    • 实体配置方式
    • LINQ 查询基础

  3. 第 3-4 周：关系映射 + 迁移

    • 一对多关系配置
    • 迁移工作流
    • 实战：构建博客系统或电商后台

学习方法：

  • ✅ 每个章节都动手编写示例代码
  • ✅ 完成至少一个完整项目
  • ✅ 使用 快速参考 查阅 API

Web 开发工程师（6 个月 -2 年经验） ​

目标：优化现有项目性能，掌握高级查询技巧

学习路径：

  1. 性能优化专题（1-2 周）

    • 性能优化原则概览
    • AsNoTracking 与无跟踪查询
    • 避免 N+1 查询
    • 投影查询减少数据传输
    • 分页查询 Skip/Take

  2. 高级查询专题（1 周）

    • 预加载 Include/ThenInclude
    • 复杂查询：分组聚合联接
    • 原始 SQL 查询
    • 查询拆分 AsSplitQuery

  3. 调试与监控（3-5 天）

    • 启用日志 LogTo
    • 查看生成的 SQL
    • MiniProfiler 分析

实战项目：

  • 优化现有项目的慢查询（目标：响应时间降低 50%）
  • 实现通用分页组件
  • 添加性能监控中间件

高级开发工程师/架构师（2+ 年经验） ​

目标：设计可扩展的数据访问层，解决复杂业务场景

学习路径：

  1. 底层原理（1 周）

    • 变更跟踪 ChangeTracker 原理
    • 查询管道与 LINQ 翻译
    • DbContext 生命周期详解

  2. 架构设计（1-2 周）

    • 仓储模式是否需要？
    • Clean Architecture/DDD 中使用 EF Core
    • 多租户支持
    • 分库分表方案

  3. 高级特性（1 周）

    • 全局查询筛选器
    • 继承映射 TPH/TPT/TPC
    • JSON 列支持
    • 预编译查询

  4. 并发与事务（3-5 天）

    • 乐观并发控制原理
    • 处理 DbUpdateConcurrencyException

  5. 测试策略（3-5 天）

    • InMemory 数据库的局限
    • Testcontainers 集成测试

架构决策：

  • 评估是否引入仓储模式
  • 设计多租户数据隔离方案
  • 制定团队 EF Core 编码规范

  2. 变更跟踪原理
  3. AsNoTracking 优化
  4. 内存优化与对象池化

🛠️ 实战项目建议 ​

项目 1：博客系统（初级） ​

技术点：

  • 基础 CRUD
  • 一对多关系（文章-评论）
  • 多对多关系（文章-标签）
  • 分页查询

功能模块：

  • 用户管理
  • 文章发布
  • 评论系统
  • 标签分类

项目 2：电商平台（中级） ​

技术点：

  • 复杂查询（订单统计）
  • 事务处理
  • 乐观并发（库存扣减）
  • 性能优化（缓存、索引）

功能模块：

  • 商品管理
  • 购物车
  • 订单处理
  • 支付集成
  • 库存管理

项目 3：SaaS 多租户系统（高级） ​

技术点：

  • 全局查询过滤器（租户隔离）
  • 多租户数据隔离
  • 软删除
  • 审计日志
  • 分库分表

功能模块：

  • 租户管理
  • 用户权限
  • 数据隔离
  • 订阅计费

❓ 常见问题 ​

Q: 我应该从哪个版本开始学习？ ​

A: 推荐从 .NET 8 (LTS) 开始，这是长期支持版本，稳定性好，生态系统完善。

Q: 需要预先掌握哪些知识？ ​

A:

  • C# 基础语法
  • LINQ 基本用法
  • SQL 基础知识
  • 面向对象编程概念

Q: 学完这个知识库能找到工作吗？ ​

A: 本知识库覆盖企业中常用的 EF Core 技能，配合项目实战，能够满足大多数 .NET 后端开发岗位的要求。

Q: 多久能学完？ ​

A:

  • 初级路径：1 个月（每天 2 小时）
  • 中级路径：2-3 个月
  • 高级路径：3-6 个月
