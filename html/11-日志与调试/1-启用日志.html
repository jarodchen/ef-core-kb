启用日志 ​

概述 ​

EF Core 内置了强大的日志记录功能,可以记录 SQL 查询、命令执行、变更跟踪等详细信息。正确配置日志对于调试问题、性能优化和生产监控至关重要。

日志级别 ​

级别说明适用场景
Trace最详细的信息深度调试
Debug调试信息开发环境
Information一般信息(SQL 命令)✅ 开发/测试
Warning警告(客户端评估)⚠️ 需要注意
Error错误(异常)❌ 需要修复
Critical严重错误🚨 立即处理
None不记录生产环境(部分)

性能监控 ​

记录慢查询 ​

csharp
public class SlowQueryLogger
{
    private readonly ILogger<SlowQueryLogger> _logger;
    private readonly TimeSpan _threshold = TimeSpan.FromSeconds(1);

    public SlowQueryLogger(ILogger<SlowQueryLogger> logger)
    {
        _logger = logger;
    }

    public void LogIfSlow(string message)
    {
        // 解析执行时间(从日志消息中提取)
        if (message.Contains("Executed DbCommand"))
        {
            var match = System.Text.RegularExpressions.Regex.Match(
                message, @"Executed DbCommand \((\d+)ms\)");
            
            if (match.Success && int.TryParse(match.Groups[1].Value, out int ms))
            {
                if (TimeSpan.FromMilliseconds(ms) > _threshold)
                {
                    _logger.LogWarning("SLOW QUERY ({Ms}ms): {Message}", ms, message);
                }
            }
        }
    }
}

// 使用
var slowQueryLogger = new SlowQueryLogger(loggerFactory.CreateLogger<SlowQueryLogger>());

options.LogTo(
    message =>
    {
        Console.WriteLine(message);
        slowQueryLogger.LogIfSlow(message);
    },
    LogLevel.Information);

统计查询次数 ​

csharp
public class QueryCounter
{
    private int _queryCount = 0;
    private long _totalExecutionTime = 0;

    public void CountQuery(string message)
    {
        if (message.Contains("Executed DbCommand"))
        {
            Interlocked.Increment(ref _queryCount);
            
            var match = System.Text.RegularExpressions.Regex.Match(
                message, @"Executed DbCommand \((\d+)ms\)");
            
            if (match.Success && int.TryParse(match.Groups[1].Value, out int ms))
            {
                Interlocked.Add(ref _totalExecutionTime, ms);
            }
        }
    }

    public void PrintStats()
    {
        Console.WriteLine($"Total Queries: {_queryCount}");
        Console.WriteLine($"Total Execution Time: {_totalExecutionTime}ms");
        Console.WriteLine($"Average Execution Time: {_queryCount > 0 ? _totalExecutionTime / _queryCount : 0}ms");
    }
}

诊断源(DiagnosticSource) ​

订阅诊断事件 ​

csharp
using System.Diagnostics;

public class EfCoreDiagnosticObserver : IObserver<KeyValuePair<string, object>>
{
    private readonly ILogger<EfCoreDiagnosticObserver> _logger;

    public EfCoreDiagnosticObserver(ILogger<EfCoreDiagnosticObserver> logger)
    {
        _logger = logger;
    }

    public void OnCompleted()
    {
    }

    public void OnError(Exception error)
    {
        _logger.LogError(error, "Diagnostic error");
    }

    public void OnNext(KeyValuePair<string, object> value)
    {
        switch (value.Key)
        {
            case "Microsoft.EntityFrameworkCore.Database.Command.CommandExecuting":
                var command = (DbCommand)value.Value.GetType().GetProperty("Command")!.GetValue(value.Value)!;
                _logger.LogInformation("Executing: {CommandText}", command.CommandText);
                break;
                
            case "Microsoft.EntityFrameworkCore.Database.Command.CommandExecuted":
                var duration = (TimeSpan)value.Value.GetType().GetProperty("Duration")!.GetValue(value.Value)!;
                _logger.LogInformation("Executed in {Duration}ms", duration.TotalMilliseconds);
                break;
        }
    }
}

// 注册
var observer = new EfCoreDiagnosticObserver(loggerFactory.CreateLogger<EfCoreDiagnosticObserver>());
var subscription = DiagnosticListener.AllListeners.Subscribe(observer);

总结 ​

日志配置速查表 ​

场景配置
开发调试LogTo(Console.WriteLine, Information) + EnableSensitiveDataLogging()
生产监控LogTo(logger.LogError, Error)
性能分析自定义拦截器记录慢查询
单元测试LogTo(testOutput.WriteLine, Debug)
问题排查LogTo(Console.WriteLine, Debug) + 所有类别

核心要点 ​

  1. 开发环境: 详细日志,显示参数值
  2. 生产环境: 仅记录错误,避免性能影响
  3. 敏感数据: 永远不要在生产环境启用
  4. 日志轮转: 防止磁盘空间耗尽
  5. 结构化日志: 便于后续分析和查询
