软删除(Soft Delete) ​

软删除是一种数据管理模式,通过标记记录为"已删除"状态而非物理删除,实现数据的历史追踪和恢复能力。本章将深入探讨在 EF Core 中实现软删除的多种方案,包括全局过滤器、拦截器、审计日志集成等企业级实践。

1. 软删除基础 ​

1.1 什么是软删除? ​

核心概念对比:

csharp
// ❌ 硬删除(Hard Delete) - 物理删除
var product = await context.Products.FindAsync(1);
context.Products.Remove(product);
await context.SaveChangesAsync();
// SQL: DELETE FROM Products WHERE Id = 1
// 结果: 数据永久丢失!

// ✅ 软删除(Soft Delete) - 逻辑删除
var product = await context.Products.FindAsync(1);
product.IsDeleted = true;
product.DeletedAt = DateTime.UtcNow;
product.DeletedBy = "admin";
await context.SaveChangesAsync();
// SQL: UPDATE Products SET IsDeleted = 1, DeletedAt = GETUTCDATE(), DeletedBy = 'admin' WHERE Id = 1
// 结果: 数据保留,可以恢复

软删除的优势:

  1. 数据可恢复 - 误删后可以轻松恢复
  2. 审计追踪 - 保留完整的操作历史
  3. 引用完整性 - 避免外键引用问题
  4. 合规要求 - 满足数据保留法规
  5. 数据分析 - 支持删除趋势分析

典型应用场景:

csharp
// 电商系统
- 商品下架(不是永久删除,可能重新上架)
- 订单取消(需要保留历史记录)
- 用户注销(法律要求保留交易记录)

// 内容管理系统
- 文章删除(可能需要恢复或审计)
- 评论删除(防止恶意删除证据)
- 分类移除(可能有历史关联)

// 企业系统
- 员工离职(需要保留工作记录)
- 客户流失(需要分析原因)
- 合同终止(法律要求存档)

2. 全局查询过滤器实现 ​

2.1 基础全局过滤器 ​

在 DbContext 中配置:

csharp
public class AppDbContext : DbContext
{
    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        base.OnModelCreating(modelBuilder);
        
        // 为 Product 实体添加软删除过滤器
        modelBuilder.Entity<Product>()
            .HasQueryFilter(p => !p.IsDeleted);
        
        // 为 Order 实体添加软删除过滤器
        modelBuilder.Entity<Order>()
            .HasQueryFilter(o => !o.IsDeleted);
        
        // 为所有实现 ISoftDeletable 的实体添加过滤器
        var softDeletableTypes = modelBuilder.Model.GetEntityTypes()
            .Where(t => typeof(ISoftDeletable).IsAssignableFrom(t.ClrType));
        
        foreach (var entityType in softDeletableTypes)
        {
            // 动态创建 lambda: e => !((ISoftDeletable)e).IsDeleted
            var parameter = Expression.Parameter(entityType.ClrType, "e");
            var property = Expression.Property(parameter, nameof(ISoftDeletable.IsDeleted));
            var notExpression = Expression.Not(property);
            var lambda = Expression.Lambda(notExpression, parameter);
            
            modelBuilder.Entity(entityType.ClrType).HasQueryFilter(lambda);
        }
    }
}

2.3 复合过滤器 ​

软删除 + 多租户组合:

csharp
public class MultiTenantDbContext : DbContext
{
    private readonly string _tenantId;
    
    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        foreach (var entityType in modelBuilder.Model.GetEntityTypes())
        {
            var parameter = Expression.Parameter(entityType.ClrType, "e");
            
            // 构建复合过滤条件: !IsDeleted && TenantId == currentTenant
            Expression filter = null;
            
            // 软删除过滤
            if (typeof(ISoftDeletable).IsAssignableFrom(entityType.ClrType))
            {
                var isDeletedProperty = Expression.Property(parameter, nameof(ISoftDeletable.IsDeleted));
                filter = Expression.Not(isDeletedProperty);
            }
            
            // 多租户过滤
            if (typeof(IMultiTenant).IsAssignableFrom(entityType.ClrType))
            {
                var tenantProperty = Expression.Property(parameter, nameof(IMultiTenant.TenantId));
                var tenantValue = Expression.Constant(_tenantId);
                var tenantFilter = Expression.Equal(tenantProperty, tenantValue);
                
                filter = filter != null 
                    ? Expression.AndAlso(filter, tenantFilter)
                    : tenantFilter;
            }
            
            if (filter != null)
            {
                var lambda = Expression.Lambda(filter, parameter);
                modelBuilder.Entity(entityType.ClrType).HasQueryFilter(lambda);
            }
        }
    }
}

3. 拦截器自动软删除 ​

3.1 基础软删除拦截器 ​

csharp
public class SoftDeleteInterceptor : SaveChangesInterceptor
{
    public override async ValueTask<InterceptionResult<int>> SavingChangesAsync(
        DbContextEventData eventData,
        InterceptionResult<int> result,
        CancellationToken cancellationToken = default)
    {
        var context = eventData.Context;
        if (context == null) return result;
        
        // 查找所有被标记为删除的实体
        var deletedEntries = context.ChangeTracker.Entries()
            .Where(e => e.State == EntityState.Deleted)
            .ToList();
        
        foreach (var entry in deletedEntries)
        {
            // 如果实体实现了 ISoftDeletable,转换为软删除
            if (entry.Entity is ISoftDeletable softDeletable)
            {
                // 改为更新操作
                entry.State = EntityState.Unchanged;
                
                // 设置软删除字段
                softDeletable.IsDeleted = true;
                softDeletable.DeletedAt = DateTime.UtcNow;
                softDeletable.DeletedBy = GetCurrentUserId(context);
                
                // 标记属性为已修改
                entry.Property(nameof(ISoftDeletable.IsDeleted)).IsModified = true;
                entry.Property(nameof(ISoftDeletable.DeletedAt)).IsModified = true;
                entry.Property(nameof(ISoftDeletable.DeletedBy)).IsModified = true;
            }
        }
        
        return await base.SavingChangesAsync(eventData, result, cancellationToken);
    }
    
    private string GetCurrentUserId(DbContext context)
    {
        // 从 HttpContext 获取当前用户
        var httpContextAccessor = context.GetService<IHttpContextAccessor>();
        return httpContextAccessor?.HttpContext?.User?.Identity?.Name ?? "System";
    }
}

// 注册拦截器
builder.Services.AddDbContext<AppDbContext>((sp, options) =>
{
    options.UseSqlServer(connectionString);
    var interceptor = sp.GetRequiredService<SoftDeleteInterceptor>();
    options.AddInterceptors(interceptor);
});

builder.Services.AddSingleton<SoftDeleteInterceptor>();

3.2 带原因的软删除 ​

csharp
// 定义扩展方法
public static class SoftDeleteExtensions
{
    public static void SoftRemove<TEntity>(this DbSet<TEntity> dbSet, TEntity entity, 
        string reason = null) where TEntity : class
    {
        var context = dbSet.GetService<ICurrentDbContext>().Context;
        
        if (entity is ISoftDeletableWithReason softDeletable)
        {
            softDeletable.IsDeleted = true;
            softDeletable.DeletedAt = DateTime.UtcNow;
            softDeletable.DeleteReason = reason;
            
            context.Entry(entity).State = EntityState.Modified;
        }
        else
        {
            // 回退到硬删除
            dbSet.Remove(entity);
        }
    }
}

// 使用示例
var order = await context.Orders.FindAsync(orderId);
context.Orders.SoftRemove(order, "客户申请取消订单");
await context.SaveChangesAsync();

3.3 批量软删除 ​

csharp
public static class BatchSoftDeleteExtensions
{
    /// <summary>
    /// 批量软删除(高效,单次数据库调用)
    /// </summary>
    public static async Task<int> SoftDeleteRangeAsync<TEntity>(
        this DbContext context,
        Expression<Func<TEntity, bool>> predicate,
        string deletedBy,
        CancellationToken cancellationToken = default) 
        where TEntity : class, ISoftDeletable
    {
        var now = DateTime.UtcNow;
        
        return await context.Set<TEntity>()
            .Where(predicate)
            .ExecuteUpdateAsync(setters => setters
                .SetProperty(e => e.IsDeleted, true)
                .SetProperty(e => e.DeletedAt, now)
                .SetProperty(e => e.DeletedBy, deletedBy),
                cancellationToken);
    }
}

// 使用示例
var deletedCount = await context.SoftDeleteRangeAsync(
    p => p.CategoryId == 5 && p.Price < 10,
    "admin",
    cancellationToken);

Console.WriteLine($"Soft deleted {deletedCount} products");

4. 级联软删除 ​

4.1 自动级联软删除 ​

当删除父实体时,自动软删除相关子实体:

csharp
public class CascadeSoftDeleteInterceptor : SaveChangesInterceptor
{
    public override async ValueTask<InterceptionResult<int>> SavingChangesAsync(
        DbContextEventData eventData,
        InterceptionResult<int> result,
        CancellationToken cancellationToken = default)
    {
        var context = eventData.Context;
        if (context == null) return result;
        
        var deletedEntries = context.ChangeTracker.Entries()
            .Where(e => e.State == EntityState.Deleted)
            .ToList();
        
        foreach (var entry in deletedEntries)
        {
            if (entry.Entity is ISoftDeletable softDeletable)
            {
                // 查找相关的子实体集合
                var navigations = entry.Navigations
                    .Where(n => n.IsCollection)
                    .Select(n => n.CurrentValue)
                    .OfType<IEnumerable<ISoftDeletable>>();
                
                foreach (var relatedEntities in navigations)
                {
                    foreach (var relatedEntity in relatedEntities.Where(e => !e.IsDeleted))
                    {
                        // 软删除子实体
                        relatedEntity.IsDeleted = true;
                        relatedEntity.DeletedAt = DateTime.UtcNow;
                        relatedEntity.DeletedBy = softDeletable.DeletedBy;
                    }
                }
                
                // 转换父实体为软删除
                entry.State = EntityState.Unchanged;
                softDeletable.IsDeleted = true;
                softDeletable.DeletedAt = DateTime.UtcNow;
            }
        }
        
        return await base.SavingChangesAsync(eventData, result, cancellationToken);
    }
}

4.2 条件级联软删除 ​

csharp
public class SmartCascadeSoftDeleteInterceptor : SaveChangesInterceptor
{
    public override async ValueTask<InterceptionResult<int>> SavingChangesAsync(...)
    {
        var context = eventData.Context;
        
        var deletedOrders = context.ChangeTracker.Entries<Order>()
            .Where(e => e.State == EntityState.Deleted)
            .ToList();
        
        foreach (var orderEntry in deletedOrders)
        {
            var order = orderEntry.Entity;
            
            // 只级联软删除待处理的订单
            if (order.Status == OrderStatus.Pending)
            {
                var items = await context.OrderItems
                    .Where(i => i.OrderId == order.Id && !i.IsDeleted)
                    .ToListAsync();
                
                foreach (var item in items)
                {
                    item.IsDeleted = true;
                    item.DeletedAt = DateTime.UtcNow;
                }
            }
            
            // 转换订单为软删除
            orderEntry.State = EntityState.Unchanged;
            order.IsDeleted = true;
            order.DeletedAt = DateTime.UtcNow;
        }
        
        return await base.SavingChangesAsync(...);
    }
}

5. 软删除审计与恢复 ​

5.1 软删除审计日志 ​

csharp
public class SoftDeleteAuditInterceptor : SaveChangesInterceptor
{
    private readonly List<SoftDeleteAuditRecord> _auditRecords = new();
    
    public override async ValueTask<InterceptionResult<int>> SavingChangesAsync(...)
    {
        var context = eventData.Context;
        
        var deletedEntries = context.ChangeTracker.Entries()
            .Where(e => e.State == EntityState.Deleted && e.Entity is ISoftDeletable);
        
        foreach (var entry in deletedEntries)
        {
            var softDeletable = (ISoftDeletable)entry.Entity;
            
            var audit = new SoftDeleteAuditRecord
            {
                EntityName = entry.Entity.GetType().Name,
                EntityId = GetEntityId(entry),
                DeletedAt = DateTime.UtcNow,
                DeletedBy = softDeletable.DeletedBy,
                Snapshot = JsonSerializer.Serialize(CreateSnapshot(entry))
            };
            
            _auditRecords.Add(audit);
        }
        
        return await base.SavingChangesAsync(...);
    }
    
    public override async ValueTask<int> SavedChangesAsync(...)
    {
        var context = eventData.Context;
        
        if (_auditRecords.Any())
        {
            context.Set<SoftDeleteAuditRecord>().AddRange(_auditRecords);
            await context.SaveChangesAsync(cancellationToken);
            _auditRecords.Clear();
        }
        
        return await base.SavedChangesAsync(...);
    }
    
    private Dictionary<string, object> CreateSnapshot(EntityEntry entry)
    {
        return entry.Properties.ToDictionary(
            p => p.Metadata.Name,
            p => p.CurrentValue
        );
    }
}

// 审计记录实体
public class SoftDeleteAuditRecord
{
    public long Id { get; set; }
    public string EntityName { get; set; }
    public string EntityId { get; set; }
    public DateTime DeletedAt { get; set; }
    public string DeletedBy { get; set; }
    public string Snapshot { get; set; }  // JSON
    
    // 恢复方法
    public T RestoreAs<T>() where T : class
    {
        return JsonSerializer.Deserialize<T>(Snapshot);
    }
}

5.2 数据恢复功能 ​

csharp
public class SoftDeleteRecoveryService
{
    private readonly AppDbContext _context;
    
    public SoftDeleteRecoveryService(AppDbContext context)
    {
        _context = context;
    }
    
    /// <summary>
    /// 恢复单个实体
    /// </summary>
    public async Task<bool> RestoreAsync<TEntity>(int entityId, 
        CancellationToken cancellationToken = default) where TEntity : class, ISoftDeletable
    {
        var entity = await context.Set<TEntity>()
            .IgnoreQueryFilters()
            .FirstOrDefaultAsync(e => EF.Property<int>(e, "Id") == entityId, 
                cancellationToken);
        
        if (entity == null || !entity.IsDeleted)
            return false;
        
        // 恢复软删除标记
        entity.IsDeleted = false;
        entity.DeletedAt = null;
        entity.DeletedBy = null;
        
        await context.SaveChangesAsync(cancellationToken);
        return true;
    }
    
    /// <summary>
    /// 批量恢复
    /// </summary>
    public async Task<int> RestoreRangeAsync<TEntity>(
        Expression<Func<TEntity, bool>> predicate,
        CancellationToken cancellationToken = default) 
        where TEntity : class, ISoftDeletable
    {
        return await context.Set<TEntity>()
            .IgnoreQueryFilters()
            .Where(predicate)
            .Where(e => e.IsDeleted)
            .ExecuteUpdateAsync(setters => setters
                .SetProperty(e => e.IsDeleted, false)
                .SetProperty(e => e.DeletedAt, null)
                .SetProperty(e => e.DeletedBy, null),
                cancellationToken);
    }
    
    /// <summary>
    /// 从审计日志恢复
    /// </summary>
    public async Task<TEntity> RestoreFromAuditAsync<TEntity>(long auditRecordId,
        CancellationToken cancellationToken = default) where TEntity : class
    {
        var audit = await context.Set<SoftDeleteAuditRecord>()
            .FirstOrDefaultAsync(a => a.Id == auditRecordId, cancellationToken);
        
        if (audit == null) throw new NotFoundException("Audit record not found");
        
        var entity = audit.RestoreAs<TEntity>();
        context.Set<TEntity>().Add(entity);
        await context.SaveChangesAsync(cancellationToken);
        
        return entity;
    }
    
    /// <summary>
    /// 获取已删除实体列表
    /// </summary>
    public async Task<List<TEntity>> GetDeletedAsync<TEntity>(
        int pageIndex = 0, int pageSize = 50,
        CancellationToken cancellationToken = default) where TEntity : class, ISoftDeletable
    {
        return await context.Set<TEntity>()
            .IgnoreQueryFilters()
            .Where(e => e.IsDeleted)
            .OrderByDescending(e => e.DeletedAt)
            .Skip(pageIndex * pageSize)
            .Take(pageSize)
            .ToListAsync(cancellationToken);
    }
}

protected override void OnModelCreating(ModelBuilder modelBuilder)

    modelBuilder.Entity<Order>()
        .HasIndex(o => new { o.CustomerId, o.IsDeleted, o.OrderDate })
        .HasFilter("IsDeleted = 0");
}

7.1 方案对比 ​

特性软删除历史表
实现复杂度简单复杂
查询性能略低(需过滤)高(主表干净)

csharp
// 主表使用软删除
public class Product : ISoftDeletable
{

public class ProductHistory
{
    public long Id { get; set; }
    public int ProductId { get; set; }
    public string Action { get; set; }  // Created, Updated, Deleted
    public string ChangedBy { get; set; }
    public DateTime ChangedAt { get; set; }
    public string Snapshot { get; set; }  // 完整快照
}

// 定期归档已删除数据
public class DataArchivalService
{
    public async Task ArchiveDeletedProductsAsync(DateTime beforeDate)
    {
        var productsToArchive = await context.Products
            .IgnoreQueryFilters()
            .Where(p => p.IsDeleted && p.DeletedAt < beforeDate)
            .ToListAsync();
        
        foreach (var product in productsToArchive)
        {
            // 保存到历史表
            context.ProductHistories.Add(new ProductHistory
            {
                ProductId = product.Id,
                Action = "Deleted",
                ChangedBy = product.DeletedBy,
                ChangedAt = product.DeletedAt.Value,
                Snapshot = JsonSerializer.Serialize(product)
            });
            
            // 从主表物理删除
            context.Products.Remove(product);
        }
        
        await context.SaveChangesAsync();
    }
}

总结 ​

软删除是企业级应用的核心特性:

核心价值 ​

✅ 数据安全 - 防止误删,支持恢复
✅ 审计合规 - 完整的操作历史
✅ 引用完整 - 避免外键问题

关键实现 ​

  1. 全局过滤器 - 自动过滤已删除数据
  2. 拦截器 - 透明转换硬删除为软删除
  3. 级联删除 - 自动处理关联实体
  4. 审计日志 - 追踪谁删除了什么
  5. 恢复机制 - 轻松恢复误删数据

掌握这些技巧,你可以构建安全可靠的数据管理系统!
