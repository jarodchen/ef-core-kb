DDD聚合根(Aggregate Root) ​

聚合根是领域驱动设计(DDD)中的核心概念,用于保证业务一致性和封装领域逻辑。本章将深入探讨如何在 EF Core 应用中正确实现聚合根模式,包括边界设计、不变量保护、值对象集成以及仓储模式的最佳实践。

1. 聚合根基础 ​

1.1 什么是聚合根? ​

核心概念:

csharp
// 聚合(Aggregate): 一组相关对象的集合,作为一个整体处理
// 聚合根(Aggregate Root): 聚合中唯一可以从外部访问的实体

// 示例: 订单聚合
Order (聚合根) ← 可以直接访问
  ├── OrderItem (实体,在聚合内部)
  ├── OrderItem (实体,在聚合内部)
  └── ShippingAddress (值对象,在聚合内部)

// ❌ 错误: 直接从外部访问内部实体
var item = context.OrderItems.FindAsync(123);  // 破坏了聚合边界!

// ✅ 正确: 通过聚合根访问
var order = context.Orders.Include(o => o.Items).FirstOrDefault(o => o.Id == orderId);
var item = order.Items.FirstOrDefault(i => i.Id == 123);

聚合根的职责:

✅ 封装业务逻辑 - 所有变更通过聚合根进行
✅ 保护不变量 - 确保聚合内部状态始终有效
✅ 管理生命周期 - 聚合内对象同生共死
✅ 事务边界 - 一个聚合 = 一个事务

为什么需要聚合根?

public class OrderService_NoAggregate
{
    public async Task AddOrderItemAsync(int orderId, int productId, int quantity)
    {
        var order = await _context.Orders.FindAsync(orderId);
        var product = await _context.Products.FindAsync(productId);
        
        // 问题1: 谁来验证库存?
        // 问题2: 谁来计算价格?
        // 问题3: 如果order或product为null怎么办?
        // 问题4: 业务逻辑散落在服务层,难以复用

        {
            OrderId = orderId,
            ProductId = productId,
            Quantity = quantity,

// ===== 使用聚合根 =====
public class OrderService_WithAggregate
{
    public async Task AddOrderItemAsync(int orderId, int productId, int quantity)
    {
        var order = await _orderRepository.GetByIdAsync(orderId);
        var product = await _productRepository.GetByIdAsync(productId);
        
        // 聚合根负责所有业务逻辑
        order.AddItem(product, quantity);  // 封装了验证、计算等逻辑
        
        await _orderRepository.SaveAsync(order);
    }
}

public class Order : AggregateRoot
{
    public void AddItem(Product product, int quantity)
    {
        // 1. 验证库存
        if (product.Stock < quantity)
            throw new DomainException("Insufficient stock");
        
        // 2. 验证是否已存在
        var existingItem = _items.FirstOrDefault(i => i.ProductId == product.Id);
        
        if (existingItem != null)
        {
            existingItem.IncreaseQuantity(quantity);  // 委托给子实体
        }
        else
        {
            _items.Add(new OrderItem(product.Id, product.Price, quantity));
        }
        
        // 3. 重新计算总价
        RecalculateTotal();
        
        // 4. 发布领域事件
        AddDomainEvent(new OrderItemAddedEvent(Id, product.Id, quantity));
    }
    
    private void RecalculateTotal()
    {
        TotalAmount = _items.Sum(i => i.Quantity * i.UnitPrice);
    }
}

2. 聚合设计原则 ​

2.1 聚合边界设计 ​

设计规则:

1. 小聚合优于大聚合
   ✅ Order + OrderItems
   ❌ Order + OrderItems + Customer + Products + Payments

2. 通过ID引用其他聚合
   ✅ Order.CustomerId (引用Customer聚合)
   ❌ Order.Customer (直接包含Customer聚合)

3. 一个事务只修改一个聚合
   ✅ 更新Order
   ❌ 同时更新Order和Inventory

4. 最终一致性跨聚合
   Order创建 → 发布事件 → Inventory扣减(异步)

什么是不变量?

csharp
// 不变量: 必须始终为真的业务规则

public class Order : AggregateRoot
{
    // 不变量1: 订单至少有一个订单项
    public void ValidateInvariants()
    {
        if (!_items.Any())
            throw new DomainException("Order must have at least one item");
    }
    
    // 不变量2: 总金额必须等于各分项之和
    private void RecalculateTotal()
    {
        var calculatedTotal = _items.Sum(i => i.Quantity * i.UnitPrice);
        
        if (Math.Abs(calculatedTotal - TotalAmount) > 0.01m)
            throw new DomainException($"Total mismatch: {calculatedTotal} vs {TotalAmount}");
    }
    
    // 不变量3: 已取消的订单不能添加商品
    public void AddItem(Product product, int quantity)
    {
        if (Status == OrderStatus.Cancelled)
            throw new DomainException("Cannot add items to cancelled order");
        
        // ... 添加逻辑
    }
}

3.1 聚合根基类 ​

csharp
public abstract class AggregateRoot
{
    private readonly List<IDomainEvent> _domainEvents = new();
    
    public Guid Id { get; protected set; }
    public DateTime CreatedAt { get; protected set; }
    public DateTime? UpdatedAt { get; protected set; }
    
    public IReadOnlyCollection<IDomainEvent> DomainEvents => 
        _domainEvents.AsReadOnly();
    
    protected void AddDomainEvent(IDomainEvent domainEvent)
    {
        _domainEvents.Add(domainEvent);
    }
    
    public void ClearDomainEvents()
    {
        _domainEvents.Clear();
    }
    
    // 审计追踪
    protected void SetCreatedAt(DateTime createdAt)
    {
        CreatedAt = createdAt;
    }
    
    protected void SetUpdatedAt(DateTime updatedAt)
    {
        UpdatedAt = updatedAt;
    }
}

// 实体基类(非聚合根)
public abstract class Entity
{
    public Guid Id { get; protected set; }
}

// 值对象基类
public abstract class ValueObject
{
    protected static bool EqualOperator(ValueObject left, ValueObject right)
    {
        if (left is null ^ right is null)
            return false;
        
        return left is null || left.Equals(right);
    }
    
    protected abstract IEnumerable<object> GetEqualityComponents();
    
    public override bool Equals(object obj)
    {
        if (obj == null || obj.GetType() != GetType())
            return false;
        
        var other = (ValueObject)obj;
        return GetEqualityComponents().SequenceEqual(other.GetEqualityComponents());
    }
    
    public override int GetHashCode()
    {
        return GetEqualityComponents()
            .Select(x => x != null ? x.GetHashCode() : 0)
            .Aggregate((x, y) => x ^ y);
    }
}

3.2 订单聚合完整实现 ​

csharp
public class Order : AggregateRoot
{
    private readonly List<OrderItem> _items = new();
    
    // 公共属性(只读)
    public Guid Id { get; private set; }
    public Guid CustomerId { get; private set; }
    public OrderStatus Status { get; private set; }
    public decimal TotalAmount { get; private set; }
    public ShippingAddress ShippingAddress { get; private set; } = null!;
    
    public IReadOnlyCollection<OrderItem> Items => _items.AsReadOnly();
    
    // 私有构造函数 - 强制使用工厂方法
    private Order() { }
    
    /// <summary>
    /// 创建新订单(工厂方法)
    /// </summary>
    public static Order Create(Guid customerId, ShippingAddress shippingAddress)
    {
        if (customerId == Guid.Empty)
            throw new DomainException("Customer ID is required");
        
        if (shippingAddress == null)
            throw new DomainException("Shipping address is required");
        
        var order = new Order
        {
            Id = Guid.NewGuid(),
            CustomerId = customerId,
            Status = OrderStatus.Pending,
            ShippingAddress = shippingAddress,
            TotalAmount = 0
        };
        
        order.SetCreatedAt(DateTime.UtcNow);
        order.AddDomainEvent(new OrderCreatedEvent(order.Id, order.CustomerId));
        
        return order;
    }
    
    /// <summary>
    /// 添加订单项
    /// </summary>
    public void AddItem(Guid productId, decimal unitPrice, int quantity)
    {
        // 验证不变量
        EnsureCanModify();
        
        if (quantity <= 0)
            throw new DomainException("Quantity must be positive");
        
        if (unitPrice < 0)
            throw new DomainException("Unit price cannot be negative");
        
        // 检查是否已存在相同产品
        var existingItem = _items.FirstOrDefault(i => i.ProductId == productId);
        
        if (existingItem != null)
        {
            existingItem.IncreaseQuantity(quantity);
        }
        else
        {
            _items.Add(new OrderItem(productId, unitPrice, quantity));
        }
        
        // 重新计算总价
        RecalculateTotal();
        
        AddDomainEvent(new OrderItemAddedEvent(Id, productId, quantity, unitPrice));
    }
    
    /// <summary>
    /// 移除订单项
    /// </summary>
    public void RemoveItem(Guid productId)
    {
        EnsureCanModify();
        
        var item = _items.FirstOrDefault(i => i.ProductId == productId);
        
        if (item == null)
            throw new DomainException($"Product {productId} not found in order");
        
        _items.Remove(item);
        
        RecalculateTotal();
        
        // 验证不变量: 订单至少有一个项目
        if (!_items.Any())
            throw new DomainException("Order must have at least one item");
        
        AddDomainEvent(new OrderItemRemovedEvent(Id, productId));
    }
    
    /// <summary>
    /// 确认订单
    /// </summary>
    public void Confirm()
    {
        if (Status != OrderStatus.Pending)
            throw new DomainException($"Cannot confirm order with status {Status}");
        
        if (!_items.Any())
            throw new DomainException("Cannot confirm empty order");
        
        Status = OrderStatus.Confirmed;
        SetUpdatedAt(DateTime.UtcNow);
        
        AddDomainEvent(new OrderConfirmedEvent(Id));
    }
    
    /// <summary>
    /// 取消订单
    /// </summary>
    public void Cancel(string reason)
    {
        if (Status == OrderStatus.Cancelled)
            throw new DomainException("Order already cancelled");
        
        if (Status == OrderStatus.Shipped)
            throw new DomainException("Cannot cancel shipped order");
        
        var previousStatus = Status;
        Status = OrderStatus.Cancelled;
        SetUpdatedAt(DateTime.UtcNow);
        
        AddDomainEvent(new OrderCancelledEvent(Id, previousStatus, reason));
    }
    
    /// <summary>
    /// 更新送货地址
    /// </summary>
    public void UpdateShippingAddress(ShippingAddress newAddress)
    {
        EnsureCanModify();
        
        if (newAddress == null)
            throw new DomainException("Shipping address is required");
        
        var oldAddress = ShippingAddress;
        ShippingAddress = newAddress;
        SetUpdatedAt(DateTime.UtcNow);
        
        AddDomainEvent(new ShippingAddressUpdatedEvent(Id, oldAddress, newAddress));
    }
    
    // 私有方法
    
    private void EnsureCanModify()
    {
        if (Status == OrderStatus.Cancelled)
            throw new DomainException("Cannot modify cancelled order");
        
        if (Status == OrderStatus.Shipped)
            throw new DomainException("Cannot modify shipped order");
    }
    
    private void RecalculateTotal()
    {
        TotalAmount = _items.Sum(i => i.Quantity * i.UnitPrice);
    }
}

// 订单项(实体,在聚合内部)
public class OrderItem : Entity
{
    public Guid ProductId { get; private set; }
    public decimal UnitPrice { get; private set; }
    public int Quantity { get; private set; }
    public decimal Subtotal => Quantity * UnitPrice;
    
    // 私有构造函数
    private OrderItem() { }
    
    internal OrderItem(Guid productId, decimal unitPrice, int quantity)
    {
        ProductId = productId;
        UnitPrice = unitPrice;
        Quantity = quantity;
    }
    
    internal void IncreaseQuantity(int quantity)
    {
        if (quantity <= 0)
            throw new ArgumentException("Quantity must be positive");
        
        Quantity += quantity;
    }
}

// 送货地址(值对象)
public class ShippingAddress : ValueObject
{
    public string Street { get; private set; }
    public string City { get; private set; }
    public string State { get; private set; }
    public string ZipCode { get; private set; }
    public string Country { get; private set; }
    
    private ShippingAddress() { }
    
    public ShippingAddress(string street, string city, string state, 
        string zipCode, string country)
    {
        if (string.IsNullOrWhiteSpace(street))
            throw new ArgumentException("Street is required");
        
        Street = street;
        City = city;
        State = state;
        ZipCode = zipCode;
        Country = country;
    }
    
    protected override IEnumerable<object> GetEqualityComponents()
    {
        yield return Street.ToLower();
        yield return City.ToLower();
        yield return State.ToLower();
        yield return ZipCode.ToLower();
        yield return Country.ToLower();
    }
    
    public override string ToString()
    {
        return $"{Street}, {City}, {State} {ZipCode}, {Country}";
    }
}

csharp
public class AppDbContext : DbContext
{
    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        // 配置值对象
        modelBuilder.Entity<Order>(entity =>
        {
            entity.HasKey(o => o.Id);
            
            // 配置拥有的实体类型(值对象)
            entity.OwnsOne(o => o.ShippingAddress, address =>
            {
                address.Property(a => a.Street).HasColumnName("ShippingStreet");
                address.Property(a => a.City).HasColumnName("ShippingCity");
                address.Property(a => a.State).HasColumnName("ShippingState");
                address.Property(a => a.ZipCode).HasColumnName("ShippingZipCode");
                address.Property(a => a.Country).HasColumnName("ShippingCountry");
            });
            
            // 配置集合
            entity.HasMany(o => o.Items)
                .WithOne()
                .HasForeignKey("OrderId")
                .OnDelete(DeleteBehavior.Cascade);
        });
        
        // 配置OrderItem
        modelBuilder.Entity<OrderItem>(entity =>
        {
            entity.HasKey("Id");
            entity.Property<Guid>("Id").ValueGeneratedOnAdd();
        });
    }
}

// 金钱值对象
public class Money : ValueObject
{
    public decimal Amount { get; private set; }
    public string Currency { get; private set; }
    
    private Money() { }
    
    public Money(decimal amount, string currency = "USD")
    {
        if (amount < 0)
            throw new ArgumentException("Amount cannot be negative");
        
        Amount = amount;
        Currency = currency;
    }
    
    public static Money operator +(Money a, Money b)
    {
        if (a.Currency != b.Currency)
            throw new InvalidOperationException("Cannot add different currencies");
        
        return new Money(a.Amount + b.Amount, a.Currency);
    }
    
    public static Money operator -(Money a, Money b)
    {
        if (a.Currency != b.Currency)
            throw new InvalidOperationException("Cannot subtract different currencies");
        
        return new Money(a.Amount - b.Amount, a.Currency);
    }
    
    protected override IEnumerable<object> GetEqualityComponents()
    {
        yield return Amount;
        yield return Currency;
    }
}

// 使用值对象
public class Product : AggregateRoot
{
    public Money Price { get; private set; } = null!;
    
    public void UpdatePrice(Money newPrice)
    {
        if (newPrice.Currency != Price.Currency)
            throw new DomainException("Currency mismatch");
        
        Price = newPrice;
    }
}

5.1 通用仓储接口 ​

public interface IRepository<T> where T : AggregateRoot
{
    Task<T?> GetByIdAsync(Guid id, CancellationToken ct = default);
    Task AddAsync(T aggregate, CancellationToken ct = default);
    void Remove(T aggregate);

public interface IUnitOfWork : IDisposable
{
    IOrderRepository Orders { get; }
    IProductRepository Products { get; }
    ICustomerRepository Customers { get; }
    
    Task<int> SaveChangesAsync(CancellationToken ct = default);
}

public class UnitOfWork : IUnitOfWork
{
    private readonly AppDbContext _context;
    
    public IOrderRepository Orders { get; }
    public IProductRepository Products { get; }
    public ICustomerRepository Customers { get; }
    
    public UnitOfWork(AppDbContext context)
    {
        _context = context;
        
        Orders = new OrderRepository(context);
        Products = new ProductRepository(context);
        Customers = new CustomerRepository(context);
    }
    
    public async Task<int> SaveChangesAsync(CancellationToken ct = default)
    {
        return await _context.SaveChangesAsync(ct);
    }
    
    public void Dispose()
    {
        _context.Dispose();
    }
}

// 使用
public class OrderService
{
    private readonly IUnitOfWork _unitOfWork;
    
    public async Task<Guid> CreateOrderAsync(CreateOrderRequest request)
    {
        // 1. 加载聚合
        var customer = await _unitOfWork.Customers.GetByIdAsync(request.CustomerId);
        
        // 2. 创建聚合
        var order = Order.Create(customer.Id, request.ShippingAddress);
        
        foreach (var item in request.Items)
        {
            var product = await _unitOfWork.Products.GetByIdAsync(item.ProductId);
            order.AddItem(product.Id, product.Price.Amount, item.Quantity);
        }
        
        // 3. 保存聚合
        await _unitOfWork.Orders.AddAsync(order);
        await _unitOfWork.SaveChangesAsync();
        
        return order.Id;
    }
}

public class OrderConfiguration : IEntityTypeConfiguration<Order>

    public void Configure(EntityTypeBuilder<Order> builder)
    {
        builder.ToTable("Orders");
        
        builder.HasKey(o => o.Id);
        
        builder.Property(o => o.Id)
            .ValueGeneratedNever();
        
        builder.Property(o => o.CustomerId)
            .IsRequired();
        
        builder.Property(o => o.Status)
            .HasConversion<string>()
            .HasMaxLength(50);
        
        builder.Property(o => o.TotalAmount)
            .HasColumnType("decimal(18,2)")
            .IsRequired();
        
        builder.Property(o => o.CreatedAt)
            .IsRequired();
        
        // 配置值对象
        builder.OwnsOne(o => o.ShippingAddress, address =>
        {
            address.Property(a => a.Street).HasColumnName("ShippingStreet").HasMaxLength(200);
            address.Property(a => a.City).HasColumnName("ShippingCity").HasMaxLength(100);
            address.Property(a => a.State).HasColumnName("ShippingState").HasMaxLength(100);
            address.Property(a => a.ZipCode).HasColumnName("ShippingZipCode").HasMaxLength(20);
            address.Property(a => a.Country).HasColumnName("ShippingCountry").HasMaxLength(100);
        });
        
        // 配置集合
        builder.HasMany(o => o.Items)
            .WithOne()
            .HasForeignKey("OrderId")
            .OnDelete(DeleteBehavior.Cascade);
        
        // 索引
        builder.HasIndex(o => o.CustomerId);
        builder.HasIndex(o => o.Status);
        builder.HasIndex(o => o.CreatedAt);
    }
}

            {
                Id = o.Id,
                CustomerId = o.CustomerId,
                TotalAmount = o.TotalAmount,
                ItemCount = o.Items.Count

            .FirstOrDefaultAsync();

总结 ​

聚合根是DDD的核心模式:

核心价值 ​

✅ 业务封装 - 逻辑集中在领域层
✅ 数据一致性 - 不变量得到保护
✅ 清晰边界 - 职责明确,易于维护

关键实现 ​

  1. 小聚合 - 3-5个实体最佳
  2. ID引用 - 跨聚合通过ID
  3. 工厂方法 - 控制创建逻辑
  4. 值对象 - 封装概念整体
  5. 仓储模式 - 抽象数据访问

掌握聚合根,你可以构建高内聚、低耦合的领域模型!
