🔍 版本详解 ​

EF Core 1.x（已停止支持） ​

发布时间：2016 年 6 月
基于框架：.NET Core 1.x

主要特性 ​

  • ✅ 跨平台支持
  • ✅ 代码优先（Code First）
  • ✅ LINQ 查询
  • ✅ 迁移系统

局限性 ​

  • ❌ 功能不完整（相比 EF 6）
  • ❌ 不支持延迟加载
  • ❌ 不支持存储过程
  • ❌ 性能一般

建议：不要使用，已过时。

EF Core 2.0/2.1（已停止支持） ​

发布时间：2017-2018 年
LTS 版本：2.1（支持至 2021 年 8 月）

新特性 ​

  • ✅ 改进的 LINQ 翻译
  • ✅ 全局查询过滤器
  • ✅ DbContext 池化
  • ✅ 显式编译查询

典型应用 ​

csharp
// EF Core 2.1 引入全局过滤器
modelBuilder.Entity<Product>(entity =>
{
    entity.HasQueryFilter(p => !p.IsDeleted); // 软删除
});

EF Core 3.0/3.1（扩展支持中） ​

发布时间：2019 年
LTS 版本：3.1（支持至 2022 年 12 月，部分扩展支持）

重大变更 ​

  • ⚠️ 客户端评估移除：所有查询必须在服务器端执行
  • ✅ 改进的性能
  • ✅ 更好的 SQL 生成

破坏性变更示例 ​

csharp
// ❌ EF Core 3.0+ 不再支持
var customers = context.Customers
    .Where(c => c.Name.StartsWith(ExpensiveClientMethod())) // 运行时异常
    .ToList();

// ✅ 必须改为
var customers = context.Customers
    .Where(c => c.Name.StartsWith("A"))
    .ToList();

EF Core 5.0（已停止支持） ​

发布时间：2020 年 11 月
基于框架：.NET 5

新特性 ​

  • ✅ 多对多关系（无需显式连接表）
  • ✅ 简单日志记录
  • ✅ 过滤 Include
  • ✅ 单个查询拆分

多对多关系简化 ​

csharp
// EF Core 5.0 之前
modelBuilder.Entity<Post>()
    .HasMany(p => p.Tags)
    .WithMany(t => t.Posts)
    .UsingEntity<Dictionary<string, object>>(
        "PostTag",
        j => j.HasOne<Tag>().WithMany().HasForeignKey("TagId"),
        j => j.HasOne<Post>().WithMany().HasForeignKey("PostId"));

// EF Core 5.0+
modelBuilder.Entity<Post>()
    .HasMany(p => p.Tags)
    .WithMany(t => t.Posts);

🌟 重大新特性 ​

1. 批量操作 API ​
csharp
// 批量删除
await context.Products
    .Where(p => p.IsObsolete)
    .ExecuteDeleteAsync();

// 批量更新
await context.Products
    .Where(p => p.Category == "Old")
    .ExecuteUpdateAsync(setters => setters
        .SetProperty(p => p.Category, "New")
        .SetProperty(p => p.UpdatedAt, DateTime.UtcNow));

📅 支持周期说明 ​

Microsoft 支持政策 ​

LTS（长期支持）版本 ​

  • 支持周期：3 年
  • 更新类型：安全补丁 + Bug 修复
  • 适用场景：生产环境、企业应用

STS（短期支持）版本 ​

  • 支持周期：18 个月
  • 更新类型：安全补丁 + Bug 修复 + 小特性
  • 适用场景：技术尝鲜、快速迭代

💬 常见问题 ​

Q: 我应该使用哪个版本？ ​

A:

  • 生产环境：EF Core 8.0 LTS
  • 学习实验：EF Core 9.0
  • 遗留维护：至少 3.1+，计划升级

Q: LTS 和 STS 有什么区别？ ​

A:

  • LTS：3 年支持，适合生产环境
  • STS：18 个月支持，适合技术尝鲜

Q: 如何知道何时需要升级？ ​

A:

  • 当前版本支持即将结束
  • 需要新版本的功能
  • 遇到已修复的 Bug
  • 性能要求提升

Q: 升级风险大吗？ ​

A:

  • 小版本升级（8.0 → 8.1）：风险低
  • 大版本升级（7.0 → 8.0）：需测试
  • 跨多版本升级（6.0 → 8.0）：谨慎评估

总结：选择合适的版本是项目成功的基础。对于大多数场景，EF Core 8.0 LTS 是当前最佳选择。
