EF Core 知识库 ​

基于 .NET 8 / 9 / 10 的 Entity Framework Core 完整技术指南

📖 简介 ​

本知识库系统化整理了 Entity Framework Core 的核心概念、最佳实践、性能优化技巧和企业级应用方案。内容涵盖从基础入门到高级特性的完整知识体系，适用于使用 .NET 8/9/10 进行数据访问层开发的开发者。

🎯 适用人群 ​

  • 初学者：快速掌握 EF Core 基础概念和 CRUD 操作
  • 中级开发者：深入理解查询管道、关系映射和性能优化
  • 高级开发者：探索并发控制、分布式架构和底层原理
  • 架构师：设计分层架构、多租户系统和微服务数据访问

💡 最佳实践提示 ​

性能优化黄金法则：

  1. 只查询需要的数据（投影）
  2. 避免 N+1 查询（Include vs 循环）
  3. 无追踪查询用于只读场景（AsNoTracking）
  4. 合理使用索引
  5. 监控生成的 SQL

🛠️ 常用命令速查 ​

bash
# 添加迁移
dotnet ef migrations add InitialCreate

# 应用迁移
dotnet ef database update

# 生成 SQL 脚本
dotnet ef migrations script

# 移除迁移
dotnet ef migrations remove

# 查看迁移列表
dotnet ef migrations list
